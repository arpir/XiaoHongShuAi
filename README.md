## 📖 项目简介

**小红书全能 AI 助手** 是一个基于 Tampermonkey (油猴) 的浏览器脚本，提供四大核心功能：

1. **📊 数据导出**：采用 API 拦截技术，支持导出用户笔记、收藏、点赞、**搜索结果**等数据。**支持 Excel (带图)、HTML (离线查看)、Markdown** 等多种格式。
2. **📥 资源下载**：支持提取笔记中的高清无水印图片、视频，批量下载时自动归档到**以笔记标题命名的文件夹**。
3. **🤖 AI 创作**：内置多种写作模版，**支持 AI 自动生成人设与提示词**，快速生成高质量种草笔记。
4. **📈 AI 分析**：对捕获的数据进行智能总结、趋势分析，或利用 AI 重新分类整理。

**V2.6 版本更新：**

- ✅ **面板交互重构**：助手默认收起为可拖拽的红色圆点（位置自动记忆），点击后在**浏览器右侧固定停靠**展开，面板高度 = 浏览器高度，内容区独立滚动；展开态不可拖动，避免误触。
- ✅ **Pinterest 设计系统**：全新视觉规范——Pinterest Red 仅用于主按钮/激活态/品牌标识，暖奶油中性 Chrome，16px / 32px / 胶囊三档圆角，纯系统字体（零第三方字体依赖）。
- ✅ **资源下载归档**：批量下载的选中资源自动保存到**以笔记标题命名的文件夹**中，不再平铺在下载目录。
- ✅ **动画优化**：展开/收起改为纯合成属性动画（淡入 + 滑入），消除大幅面重绘卡顿。
- ✅ **界面净化**：移除全部装饰性 emoji（仅保留 AI 相关 🧠），标题栏与设置页去图标化，按钮收敛为「红主 / 奶油次」双色。
- ✅ **导出字段修复**：修复点击字段无法切换选中状态的问题（初始化异常导致事件绑定中断）。

## ✨ 核心功能

### 📊 数据导出功能

- **多页面支持**：
  - ✅ 用户主页（笔记列表）
  - ✅ 收藏夹
  - ✅ **点赞列表**
  - ✅ 首页推荐
  - ✅ **搜索结果页**（深度兼容多种数据结构）
- **多格式支持**：
  - **Excel (永久嵌入图)**：直接在表格中查看封面图，支持分包。
  - **HTML (网页还原)**：**[NEW]** 离线单文件，图片Base64内嵌，永久保存。
  - **Markdown**：适合导入 Obsidian/Notion。
  - **JSON / CSV**：方便开发者二次开发。
- **智能分包 (Batch Export)**：防止数据量过大导致浏览器崩溃，支持自定义每包数据条数，自动连续下载。
- **永久有效链接**：导出的 CSV/JSON 链接包含 `xsec_token`，确保可直接访问。

### 📥 资源下载功能

- **无水印提取**：自动解析笔记中的高清图片（排除水印）和视频源文件
- **场景自适应**：
  - **自动检测**：在笔记详情页打开面板，自动捕捉当前笔记资源
  - **手动输入**：支持粘贴其他笔记链接进行提取
- **批量管理**：可视化预览网格，支持全选/多选，一键批量下载
- **文件夹归档**：下载的文件自动保存到以笔记标题命名的文件夹中（非法字符自动替换），多篇笔记的资源互不混淆

### 🤖 AI 创作功能

- **多模型支持**：完美兼容 DeepSeek、Kimi (Moonshot)、ChatGPT 等支持 OpenAI 接口格式的模型
- **🧠 AI 生成人设**：不会写 Prompt？只需输入"你是谁"（如：资深美妆博主），AI 自动帮你写好所有配置。
- **模板管理**：可视化的模版管理，支持自定义与增删改查。
- **一键填充**：生成后自动将标题和正文填入小红书发布框。

### 📈 AI 分析功能

- **智能总结**：上传 CSV/JSON 文件，AI 自动分析数据趋势、用户反馈与热门话题
- **智能分类**：
  - 自定义分类维度（如：穿搭风格、内容类型、情感倾向）
  - AI 自动批量对笔记进行归类整理
  - 内置 API 速率限制保护，支持断点续传
- **结果导出**：分析与分类后的结果支持导出为 **Excel**、CSV 或 JSON

### ⚙️ 高级配置

- **多配置管理**：可保存多个 API Key 配置（如同时配置 DeepSeek 和 Kimi），随时切换
- **模型自动获取**：输入 BaseURL 和 Key 后，可一键拉取可用模型列表
- **独立面板**：设置页独立分栏，操作更便捷

## 📥 安装指南

1. **安装油猴插件**：  
   确保你的浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展 (Chrome/Edge/Firefox)。
2. **安装脚本**：
   - [点击此处安装](https://greasyfork.org/en/scripts/600161-%E5%B0%8F%E7%BA%A2%E4%B9%A6%E5%85%A8%E8%83%BDai%E5%8A%A9%E6%89%8B)
   - 或者在 Tampermonkey 中新建脚本，将脚本内容完整复制进去并保存。
3. **打开小红书**：  
   访问 [小红书](https://www.xiaohongshu.com/) 或 [创作服务平台](https://creator.xiaohongshu.com/publish/publish)，页面右侧会出现一个**红色圆形图标**。

### 面板操作方式

| 操作               | 效果                                      |
| ---------------- | --------------------------------------- |
| **拖拽红色圆点**       | 图标可移动到屏幕任意位置，位置自动记忆（刷新/重开浏览器后保留）        |
| **点击红色圆点**       | 在浏览器**右侧固定位置**展开面板，面板高度与浏览器一致，内容区独立上下滚动 |
| **点击标题栏 "_" 按钮** | 收起面板，图标回到上次拖拽的位置                        |

> 展开态面板为固定停靠，不可拖动，避免误触移位；小屏设备下面板自动收窄。

## 📊 数据导出使用说明

### 使用方法

1. 进入目标页面（用户主页、收藏夹、点赞列表等）
2. 滚动页面或点击「自动滚动加载全部」按钮
3. 观察「当前已捕获」计数增长
4. 选择导出格式（Excel/CSV/JSON）
5. 点击「导出所有捕获数据」
6. 如需减少导出列，点击「导出字段」中的字段筹码即可切换选中/取消

### 导出字段说明

| 字段      | 说明                           |
| ------- | ---------------------------- |
| 笔记 ID   | 笔记唯一标识                       |
| 标题      | 笔记标题                         |
| 链接      | 带 xsec_token 的永久有效链接         |
| 作者      | 笔记作者昵称                       |
| 点赞数     | 笔记点赞数量                       |
| 类型      | 笔记类型（normal/video 等）         |
| **封面图** | **笔记封面图片链接 (Excel模式下可显示图片)** |

### 注意事项

- 页面切换时数据会自动清空，确保数据清洁性
- 如需导出不同页面的数据，请分别导出
- 建议使用 CSV 格式，可直接用 Excel 打开

## 📥 资源下载使用说明

该功能允许你下载高清无水印的笔记配图和视频。

1. **自动检测模式**：
   - 打开某个笔记的详情页（链接通常为 `xiaohongshu.com/explore/xxxx`）
   - 打开助手面板，切换到「**资源下载**」标签（检测到当前页资源时标签会红色高亮提示）
   - 点击「**提取资源**」即可
2. **手动输入模式**：
   - 在任何页面，将小红书笔记链接粘贴到输入框中
   - 点击提取按钮
3. **批量下载**：
   - 提取成功后，预览区会显示所有图片/视频
   - 默认全选，你可以点击图片取消选择
   - 点击「**批量下载选中资源**」，文件将自动保存到**以该笔记标题命名的文件夹**中

## 📈 AI 分析使用说明

### 1. 智能总结

1. 切换到 **[AI分析]** 标签页。
2. 点击文件上传区域，选择之前导出的 CSV 或 JSON 数据文件。
3. 点击 **"🧠 生成总结分析"**，AI 将读取文件内容并生成一份详细的数据分析报告。

### 2. 智能分类

1. 在 **[AI分析]** 标签页下方，输入你想要的自定义分类（如：`好物, 避雷, 教程`），用逗号分隔。
2. 选择导出格式（Excel/CSV/JSON）。
3. 点击 **"智能分类并导出"**。
4. 脚本将自动调用 AI 逐条分析笔记内容，并打上最匹配的分类标签，最后合并导出新文件。

## ⚙️ 模型配置教程

本插件支持多组 API 配置切换。点击 **"设置"** 标签页进行管理。

### 1. 添加新配置

1. 点击配置下拉框旁边的 **"+"** 按钮。
2. 填入服务商的 API 信息：
   - **Base URL**: 接口地址 (需包含 `/v1/chat/completions` 或兼容 OpenAI 格式的完整路径)
   - **API Key**: 你的 API 密钥
3. 点击 **"获取"** 按钮尝试拉取模型列表，或手动输入模型名称。
4. 配置将自动保存。

### 推荐模型配置

#### 1. DeepSeek (深度求索)

- **Base URL**: `https://api.deepseek.com`
- **Model**: `deepseek-chat`

#### 2. Kimi (Moonshot AI)

- **Base URL**: `https://api.moonshot.cn/v1/chat/completions`
- **Model**: `moonshot-v1-8k`

## 🛠 自定义模板

点击输入框下方的 **"管理模版"** 按钮即可打开模板编辑器。

### 🧠 AI 生成人设 (懒人模式)

1. 点击 **"新增模版"**
2. 找到 **"输入模版人设/要求"** 的输入框
3. 随便写点什么，例如：`你是一个严厉的健身教练，说话很冲，但是干货很多`
4. 脚本会自动为你生成匹配的 System Prompt 和 Prompt，无需动脑！

### 变量说明

在编写 Prompt (提示词) 时，使用以下占位符，AI 生成时会自动替换为你输入的内容：

- `{{title}}` ：对应主面板的 **输入框 1** (通常用于产品名/书名/主题)
- `{{content}}` ：对应主面板的 **输入框 2** (通常用于详细描述/剧情/痛点)

### 示例：创建一个 "情感语录" 模板

1. **模板名称**: 情感语录
2. **System Prompt**: `你是一个情感博主，擅长写扎心的文案。`
3. **User Prompt**:
   ```text
   请以{{title}}为主题，写一段关于{{content}}的情感文案。
   要求：
   1. 标题要痛彻心扉。
   2. 正文多用短句，分行排版。
   3. 结尾带Tag。
   输出JSON格式：{"title": "...", "content": "..."}
   ```
